# 🍿 NodeFlix - Frontend 

## 🛠️ Tecnologías Utilizadas
* **Framework:** Angular 21
* **Estilos:** Tailwind CSS
* **Lenguaje:** TypeScript

## 📋 Requisitos Previos
Antes de descargar el proyecto, asegúrate de tener instalado:
1. **Node.js** (Versión 22 LTS recomendada).
2. **Angular CLI v21**: Si no lo tienes, instálalo globalmente ejecutando:
   `npm install -g @angular/cli@21`

## 🚀 Instalación y Ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/TU-USUARIO/nodeflix-frontend.git](https://github.com/TU-USUARIO/nodeflix-frontend.git)
   cd nodeflix-frontend


2. **Instalar dependencias:**
   ```bash
   npm install

2. **Levantar el servidor de desarrollo:**
   ```bash
   ng serve
